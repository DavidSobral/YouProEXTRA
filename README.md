# YouProEXTRA
YouTube IPA builder packed with customizable tweaks. Also Known as Youtubemaxxing.

## Main features
- **[YouPro](https://t.me/alibusut)** - Basic Youtube Premium features; Download Videos, No ads, Background Playback.
- **[YoutubePlus/YTLite](https://github.com/dayanch96/YTLite)** - A flexible enhancer for YouTube on iOS, featuring over hundred customizable options.
- **[YTKillerPlus](https://repo.ikghd.me/depictions/?p=me.ikghd.ytkplus)** - Alternative Youtube tweak with more customized options.
- **[YouMod](https://github.com/Tonwalter888/YouMod)** - a free alternative youtube tweak.
- **[LRD](https://t.me/LRD_Update)/[DLTube](https://x.com/dltweaks_)** - more optional YouTube tweaks. Download Videos, No ads and Background Playback.
- **[YTKACE](https://github.com/Epic0001/YTKACE)** - A new free and open-source YouTube enhancer for iOS with downloads, SponsorBlock, player controls, and interface customization.
- **[YTMusicUltimate](https://github.com/mrdrvt99/YTMusicUltimate)** - Background playback, ad removal, Downloads and other small improvements.

## How to build a YouProEXTRA IPA using Github Actions
> [!NOTE]
> Make sure to provide a **direct download link** to the file, not a link to a webpage. Otherwise, the process will fail.

<details>
<summary>How to build a YouProEXTRA IPA</summary>

1. Click on **Sync fork**, and if your branch is out-of-date, click on **Update branch**.
2. Navigate to **Actions** in your forked repository and select **Build YouPro/YTLite/YTKillerPlus IPA**.
3. Click the **Run workflow** button located on the right side.
4. Get a decrypted `.ipa` file (I cannot provide this due to legal reasons.), then upload it to a file provider (e.g., buzzheavier.com, filemail.com, catbox.moe, or Dropbox are recommended). Paste the URL of the decrypted IPA file in the provided field.
5. Integrate the tweaks from the drop down menu, and if you want you can also change the BundleID and Display Name if desired.
6. Make sure all inputs are correct, then click **Run workflow** to start the process.
7. Wait for the build to finish. You can download the YouProEXTRA IPA from the **Releases** section of your forked repo.  
   (If you can't find the Releases section, go to your forked repo and add `/releases` to the URL, i.e., `github.com/yourusername/YouProEXTRA/releases`.)

</details>

<details>
<summary>How to build a YouProEXTRA IPA (With your own .deb file)</summary>

1. Click on **Sync fork**, and if your branch is out-of-date, click on **Update branch**.
2. Navigate to **Actions** in your forked repository and select **Build IPA with Custom .deb tweak**.
3. Click the **Run workflow** button located on the right side.
4. Get a decrypted `.ipa` file (I cannot provide this due to legal reasons.), then upload it to a file provider (e.g., buzzheavier.com, filemail.com, catbox.moe, or Dropbox is recommended). Paste the URL of the decrypted IPA file in the provided field.
5. Get your Custom `.deb` file, then upload it to a file provider (e.g., buzzheavier.com, catbox.moe, or Dropbox are recommended). Paste the URL of the deb file in the provided field.
6. Integrate the tweaks from the drop down menu, and if you want you can also change the BundleID and Display Name if desired.
7. Make sure all inputs are correct, then click **Run workflow** to start the process.
8. Wait for the build to finish. You can download the YouProEXTRA IPA from the **Releases** section of your forked repo.  
   (If you can't find the Releases section, go to your forked repo and add `/releases` to the URL, i.e., `github.com/yourusername/YouProEXTRA/releases`.)

</details>

> [!CAUTION]
> Custom build compiles all the tweaks available in the repo. It may crash your custom IPA. Test every tweak.

> [!IMPORTANT]
> If you modified any workflow files, delete the existing caches in the Actions tab before running a new build.
